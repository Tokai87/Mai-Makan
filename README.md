# JomMakan.my — Direktori Port Makan All-in-One Malaysia

Aplikasi web mudah alih (PWA-ready) untuk meneroka dan berkongsi tempat makan terbaik di kesemua 14 negeri di Malaysia.

## Ciri-Ciri Utama
- **Carian Lokasi GPS ("Dekat Saya")**: Mengesan lokasi semasa pengguna dan menyusun senarai kedai makan dari jarak paling hampir (km).
- **Direktori 14 Negeri**: Liputan awal lebih daripada 56 port makan ikonik merangkumi Perlis, Kedah, Pulau Pinang, Perak, Selangor, Kuala Lumpur, Negeri Sembilan, Melaka, Johor, Pahang, Terengganu, Kelantan, Sabah, dan Sarawak.
- **Pemilih Rawak Pintar ("Buntu Nak Makan Apa?")**: Memilih cadangan tempat makan secara rawak mengikut negeri atau kategori yang dipilih.
- **Integrasi Navigasi**: Terus membuka arah perjalanan melalui Google Maps atau Waze dengan satu klik.
- **Penyesuaian Tema & Latar Belakang**: Menyokong 5 pilihan warna tema (termasuk *Midnight Dark Mode*) dan 3 gaya latar belakang.
- **Simpanan Kegemaran & Tambah Port Baharu**: Data disimpan terus dalam pelayar pengguna (`localStorage`).

## Cara Deploy ke GitHub Pages / Vercel
1. Muat naik fail `index.html` dan `README.md` ke repositori GitHub anda.
2. Aktifkan **GitHub Pages** di bahagian *Settings > Pages* (pilih branch `main` dan folder `/root`), atau sambungkan repositori terus ke **Vercel** / **Netlify**.
